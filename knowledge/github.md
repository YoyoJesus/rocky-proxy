# HacKSU GitHub projects and lessons

Public repository directory reviewed October 21, 2026. The HacKSU GitHub organization is
[github.com/hacksu](https://github.com/hacksu). This is a selected directory; more repositories
are available on the organization page. README contents are indexed separately and refreshed
from the public repositories. Older lessons describe the tools used at the time of the workshop.

## Club and event websites

- [hacksu-recant](https://github.com/hacksu/hacksu-recant): the HacKSU club website at hacksu.com.
- [khe-renaissance](https://github.com/hacksu/khe-renaissance): the Kent Hack Enough (KHE) website at khe.io.
- [kent-hack-it](https://github.com/hacksu/kent-hack-it): the Kent Hack It (KHI) CTF website at ctf.hacksu.com.

## Workshop materials

- [flask-colorpicker](https://github.com/hacksu/flask-colorpicker): learn Python web development
  with Flask by building a color picker.
- [fastapi-gemini_wrapper](https://github.com/hacksu/fastapi-gemini_wrapper): build a web AI
  chatbot with FastAPI and Gemini; the README pairs it with the Flask color picker lesson.
- [pokemongo](https://github.com/hacksu/pokemongo): a MongoDB database lesson using Pokemon.
- [effective-ai-lesson](https://github.com/hacksu/effective-ai-lesson): AI workshop agenda and
  presenter notes. Check current product documentation for offers and subscriptions mentioned there.
- [HacKSU-Presentation-Template](https://github.com/hacksu/HacKSU-Presentation-Template): a slide
  deck template for HacKSU workshops, with local preview and GitHub Pages publishing instructions.
